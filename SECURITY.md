# Política de segurança

Não publique vulnerabilidades que incluam credenciais, telefones, JIDs, nomes
de grupos, anúncios, mídias ou logs reais em uma issue comum.

Use o recurso **Report a vulnerability** na aba **Security** do GitHub para
enviar o relato de forma privada. Inclua somente o mínimo necessário para
reproduzir o problema e remova dados pessoais dos exemplos.

Se uma credencial for exposta, revogue-a ou rotacione-a antes de iniciar a
limpeza do histórico Git.
